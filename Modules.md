# Terraform Module Catalog

This repository aims to provide a central catalog of commonly used Terraform modules across various cloud providers and local environments. Below is a broad list of modules that are typically needed when building infrastructure. These modules can serve as inspiration for implementation in AWS, Azure, Google Cloud, Oracle Cloud, Snowflake, and other environments.

## AWS (Amazon Web Services)
- VPC (Virtual Private Cloud)
- Subnets (public/private)
- Security Groups
- IAM Users/Roles/Policies
- EC2 Instances and Auto Scaling
- RDS (Relational Database Service)
- S3 Buckets
- EKS (Elastic Kubernetes Service)
- ECS (Elastic Container Service)
- Lambda Functions
- CloudFront Distributions
- Route53 (DNS)
- Elastic Load Balancers

## Azure
- Resource Groups
- Virtual Networks and Subnets
- Network Security Groups
- Azure AD Users/Groups/Service Principals
- Virtual Machines and Scale Sets
- Azure Kubernetes Service (AKS)
- SQL Databases
- Storage Accounts
- Azure Functions
- Application Gateway
- DNS Zones

## Google Cloud Platform (GCP)
- VPC Networks and Subnets
- Firewall Rules
- IAM Service Accounts and Roles
- Compute Engine Instances and Instance Groups
- Google Kubernetes Engine (GKE)
- Cloud SQL
- Cloud Storage Buckets
- Cloud Functions
- Cloud Load Balancing
- Cloud DNS

## Oracle Cloud Infrastructure (OCI)
- Virtual Cloud Networks
- Subnets and Route Tables
- Security Lists
- IAM Users/Groups/Policies
- Compute Instances and Autoscaling
- Oracle Kubernetes Engine (OKE)
- Block Volume and Object Storage
- Load Balancers
- DNS

## Snowflake
- Accounts and Warehouses
- Databases, Schemas, and Tables
- Roles and Grants
- Users and Resource Monitors

## Other/Local Modules
- Local Docker Containers
- Helm Charts for Kubernetes
- Local Development Environments with Vagrant
- GitHub Actions Runners
- Monitoring/Logging stack (e.g., Prometheus, Grafana, Loki)

This list is meant to be a starting point and does not cover every possible module. Feel free to expand these modules or create new ones as the repository grows.
